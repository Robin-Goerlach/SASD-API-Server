# Java-Plugins `logging` – nicht implementiert

> **Sprache:** [English (Standard)](README.md) | **Deutsch**

Reserviert für optionale bereinigte Betriebs-/Sicherheitslogs; externe Senken dürfen nicht verpflichtend sein, und atomarer DB-Schreib-Audit bleibt Core-Aufgabe. Hier gibt es derzeit **nur Dokumentation**, keine installierten oder freigegebenen Plugins. Sicherheitskritische Vorgaben erzwingt der Core.
