# Java implementation – planned

> **Language:** **English (default)** | [Deutsch](README.de.md)

This is an **empty planned workspace**, not a runnable server. The Java core will be developed only after the PHP baseline and required review gates. It must obey the same public HTTP/JSON contracts while using its own native dependency management and plugins. `core/` is the future main server, `plugins/` holds independent extensions. No framework or runtime version is approved yet.
