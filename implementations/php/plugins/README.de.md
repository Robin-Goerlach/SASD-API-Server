# PHP 8.4-Plugins – vom Core getrennt

> **Sprache:** [English (Standard)](README.md) | **Deutsch**

Die Kategorieverzeichnisse `logging/`, `identity/`, `storage/`, `application/` sind für laufzeitspezifische, ausdrücklich geprüfte Erweiterungen vorgesehen. Die Ordner bedeuten **keine fertigen Plugins**. Kein Scanning oder ungesichertes Einbinden fremder Erweiterungen und keine ungeschützten HTTP-Routen.
