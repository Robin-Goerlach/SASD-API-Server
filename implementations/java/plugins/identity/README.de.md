# Java-Plugins `identity` – nicht implementiert

> **Sprache:** [English (Standard)](README.md) | **Deutsch**

Reserviert für optionale Anbieter zur Identitätsprüfung; Berechtigungen für Ressourcen/Felder/Datensätze verbleiben zwingend im Core. Hier gibt es derzeit **nur Dokumentation**, keine installierten oder freigegebenen Plugins. Sicherheitskritische Vorgaben erzwingt der Core.
