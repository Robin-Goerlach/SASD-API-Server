# SASD-API-Server
A lightweight, open-source REST API server designed for reusable data access across multiple applications. Features a clean, modular architecture, configurable endpoints, CRUD operations, and extensible storage adapters. Starting with MariaDB/MySQL, with support for additional databases and advanced features planned.
