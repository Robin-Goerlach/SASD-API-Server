# Sprachunabhängige API-Verträge

> **Sprache:** [English (Standard)](README.md) | **Deutsch**

Hier sollen später **versionierte HTTP/JSON-Vertragstests** für PHP, Java und C# liegen. Bis solche Dateien tatsächlich erstellt und geprüft sind, gelten `docs/technical-specification-v0.md`, `docs/technical-specification-v1.md` und ihre Anforderungen als maßgebliche Entwürfe.

Keine PHP-/Java-/C#-Plugin-APIs hier unterbringen: Sie sind laufzeitspezifisch. OpenAPI-Vertrag und sprachübergreifende Tests sind noch nicht implementiert. Die momentanen PHP-Smoke-Tests sind kein Nachweis sprachübergreifender Kompatibilität.
