# Language-independent API contracts

> **Language:** **English (default)** | [Deutsch](README.de.md)

This is the future home for **versioned HTTP/JSON contract fixtures** used by PHP, Java and C#. The authoritative planned V0 and V1 behavior remains in `docs/technical-specification-v0.md`, `docs/technical-specification-v1.md` and the corresponding requirements until validated contract files actually exist.

Do not place PHP, Java or C# plugin APIs here; they are runtime-specific. No OpenAPI definition or cross-language test suite has been implemented yet. The current PHP-only smoke tests are not cross-language acceptance evidence.
